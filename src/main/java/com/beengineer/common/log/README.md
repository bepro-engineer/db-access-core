# ディレクトリ概要：log

このディレクトリは、アプリケーション全体で使用されるログ出力処理を提供するための共通クラス群です。  
シンプルなログ出力に特化し、外部ライブラリに依存せず、設定ファイル（system.xml）をもとにログの出力先・レベル・ファイル名を自動制御します。

## 各クラスの役割

| クラス名            | 概要                                                                 |
|---------------------|----------------------------------------------------------------------|
| Logger.java         | ログ出力のエントリーポイント。静的メソッドでログを出力。初期化必須。         |
| LogWriter.java      | ログファイルへの書き込み処理を内部で担う補助クラス。                        |

## 使い方（基本構文）

### 【1】ログ出力前に初期化を行う（1回のみ）

```java
Logger.init();  // 初期化（設定ファイルのlogセクションを自動読込）
```

### 【2】ログ出力を行う

```java
Logger.out(Logger.INFO, "クラス名#メソッド名", "ユーザーID", "メッセージ内容");
```

#### 引数の意味

| 引数                  | 内容                                                     |
|-----------------------|----------------------------------------------------------|
| Logger.INFO           | 出力レベル（INFO, ERROR, DEBUG2, DEBUG3, WARN）         |
| "クラス名#メソッド名" | 呼び出し元（例："UserService#login"）                   |
| "ユーザーID"          | 操作ユーザーを識別（システムIDなど）                   |
| "メッセージ内容"      | 出力したい内容                                           |

## ログ設定ファイル（system.xml）

ログ出力のパス・ファイル名・レベルは、以下のように `system.xml` に定義されます：

```xml
<log>
    <filepath>/Users/xxxxx/logs</filepath>
    <logfile>application.log</logfile>
    <level>INFO</level>
</log>
```

この設定は、`SystemInfo.getKeyValueHash("log")` 経由で取得され、自動で反映されます。

## 注意事項

- `Logger.init()` は必ずアプリケーション起動時に一度だけ実行してください。
- ログレベルは INFO > DEBUG2 > DEBUG3 の順で詳細になります。必要な出力レベルに応じて切り替えてください。
- WARN および ERROR は重要な例外やシステム警告に使用してください。
- ファイル出力先ディレクトリが存在しない場合、自動作成はされないため事前に作成してください。

## 関連クラス

- SystemInfo.java：設定ファイルの読み込みを担当
- IniFileRead.java：XML構造の読み取り処理
