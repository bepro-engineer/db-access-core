# ディレクトリ概要：exception

このディレクトリは、共通処理で使用される独自の例外クラスを定義するためのものです。  
Java標準の例外に加え、業務システムで必要となる「システム全体で捕捉できる例外」を実現するための設計です。

## 各クラスの役割

| クラス名             | 概要                                                               |
|----------------------|--------------------------------------------------------------------|
| SystemException.java | アプリケーション全体で使用される共通の実行時例外クラス。メッセージと原因例外の保持が可能。 |

## 使い方（基本構文）

### 【1】シンプルな使用例（メッセージのみ）

```java
throw new SystemException("データベース接続に失敗しました");
```

### 【2】原因例外をラップする使用例

```java
try {
    // 処理
} catch (SQLException e) {
    throw new SystemException("SQL実行時にエラーが発生しました", e);
}
```

## SystemException の特徴

- RuntimeException を継承しているため、throws 宣言が不要
- メッセージと例外（Throwable）を保持可能
- ログや画面表示に共通のエラーメッセージを出力しやすくなる
- 呼び出し元に応じて柔軟な補足・処理が可能

## 使用上の注意

- 共通部品、業務処理、データアクセス層を問わず、エラーハンドリングを共通化するために使用してください。
- try-catch 範囲が広すぎるとデバッグが困難になるため、適切な粒度で使用することを推奨します。
- 画面層ではこの例外を捕捉し、エラー画面やログ出力につなげることを前提としてください。

## 関連クラス

- Logger.java：SystemException発生時にログ出力と組み合わせることでトラブル分析が可能
- SystemInfo.java：設定エラーなどのシステム例外に活用可能
